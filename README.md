## What I work on

- **Agentic AI**: pipelines of specialised agents built with LangChain and LangGraph, from research assistants to LLMOps workflows.
- **Retrieval and document intelligence**: RAG systems with role-based access control, audit logging and Docker deployment.
- **AI safety in practice**: guardrails for input filtering, PII redaction, human-in-the-loop approval, output validation and red-team testing.
- **Machine learning and analytics**: end-to-end ML with explainability (SHAP), plus Power BI dashboards for business reporting.
